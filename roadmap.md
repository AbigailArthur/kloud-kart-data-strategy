# Kloud Kart 12-Month Data Implementation Roadmap

**Duration:** 12 months from project approval  
**Goal:** Protect the live website, establish trusted business reporting and improve customer-data control.

## Q1: Stabilise the data environment (Months 1–3)

**Main outcome:** Reporting no longer places unnecessary pressure on the live website.

| Priority action | Expected result | How Nana verifies it |
|---|---|---|
| Recruit the Data Engineer | A dedicated person is responsible for data infrastructure | Appointment completed |
| Set up the second server and read replica | Reporting reads are separated from customer transactions | Test reports run against the second server |
| Monitor database replication | Delays and failures are detected | Monitoring records and alerts are available |
| Review existing reports | Important business measures are identified | Operations and Finance report inventory completed |
| Map customer-data storage and exports | Customer information locations and owners are documented | Customer-data inventory reviewed |

**Quarter-end checkpoint:** Nana can confirm that reporting uses the second server, the live database is protected from bulk reporting queries, and the main business measures and customer-data locations have been documented.

## Q2: Establish trusted reporting (Months 4–6)

**Main outcome:** Operations and Finance work from consistent business figures.

| Priority action | Expected result | How Nana verifies it |
|---|---|---|
| Recruit the BI and Data Governance Analyst | Reporting and data-control responsibilities are assigned | Appointment completed |
| Agree on business metric definitions | Departments calculate shared measures consistently | Approved metric dictionary |
| Build daily reporting tables | Reports are prepared from a consistent source | Daily reporting output available |
| Introduce automated data-quality checks | Missing, duplicate and inconsistent records are flagged | Quality-check results recorded |
| Create shared Operations and Finance reports | Both departments use agreed figures | Four consecutive weekly reports reviewed |

**Proposed performance targets, to be confirmed after the Q1 baseline:**
- At least 98% of scheduled daily reporting refreshes complete successfully.
- Unexplained differences between agreed Operations and Finance measures fall below 0.5%.

**Quarter-end checkpoint:** Nana can compare the reports from both departments and confirm that the same agreed definitions are being used.

## Q3: Strengthen customer data controls (Months 7–9)

**Main outcome:** Customer information is easier to locate, protect and manage.

| Priority action | Expected result | How Nana verifies it |
|---|---|---|
| Introduce an export register | Marketing exports have owners, purposes and review dates | Export register reviewed |
| Introduce a customer-data request tracker | Requests have deadlines and responsible owners | Request log available |
| Document the deletion process | Relevant systems and copies are checked when requests are received | A sample request is traced through the process |
| Review external data processors | Third parties handling customer information are identified | Processor inventory completed |
| Assess Nigeria data flows | Cross-border data handling requirements are understood | Assessment reviewed with qualified privacy advice |

**Quarter-end checkpoint:** Nana can select a sample customer-data request and see when it was received, who handled it, which systems and copies were checked, and what evidence supports its completion.

The process must also consider lawful retention requirements, backups and external processors. A tracker alone does not guarantee compliance.

## Q4: Measure business value and plan the next stage (Months 10–12)

**Main outcome:** Leadership can assess the value of the improvements and decide what to invest in next.

| Priority action | Expected result | How Nana verifies it |
|---|---|---|
| Review reporting performance | Management understands whether reporting has improved | Performance report compared with Q1 baseline |
| Measure Monday reporting effort | Manual reporting work is reduced | Time spent preparing the Monday report recorded |
| Review reporting adoption | Operations and Finance regularly use shared reports | Report usage reviewed |
